# Kenali Ginjal by Fronstellar

Aplikasi web edukatif interaktif mengenai anatomi dan fisiologi ginjal.

## Buka aplikasi

https://kazadarojat.github.io/ginjal/

## Fitur

- Ilustrasi nefron dan organ sistem urinaria, filtrasi hingga miksi.
- Pelacakan molekul, hormon, hemodinamika, dan faktor produksi urin.
- Simulasi laju produksi, pengisian vesika, rasa ingin berkemih, serta kepekatan dan warna urin.

## Menjalankan secara lokal

Jalankan `python3 -m http.server 8000`, kemudian buka http://localhost:8000.

Aplikasi statis tanpa proses build. GitHub Pages menggunakan branch `main`, folder `/ (root)`.

Model disederhanakan untuk pembelajaran, bukan prediksi klinis. Lisensi font disertakan di folder `fonts`.
